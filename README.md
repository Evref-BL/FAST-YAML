# FASTYAML  

FASTYAML is a recently created project that integrates with Moose and leverages the Tree-Sitter parser to analyze YAML source code in Pharo.  

## Features  
FASTYAML relies on:  
- **[FAST][fast]**, to ensure compatibility with Moose.  
- **[Pharo-Tree-Sitter][pharo-tree-sitter]**, implemented in Pharo via the FFI protocol to efficiently parse YAML source code. It is also used to do incremental parsing.

FASTYAML metamodel is defined in a way where nodes align with those generated by Tree-Sitter.

## Installation  

To load FASTYAML in Pharo, execute the following in a Moose image:  

```smalltalk  
Metacello new  
  baseline: 'FASTYAML';  
  repository: 'github://Evref-BL/FAST-YAML:main';  
  load.
```  

## Usage

To use it, please ensure that you have installed the corresponding libraries for Tree Sitter on your machine, to ensure parsing succeeds.
Normally, this has been automated for different operating systems.
But for more details, you can have a look at this [blog-post][tree-sitter-blog].

To use it in Pharo, you can check example below:

```smalltalk  
res := FASTYAMLImporter new parse:  '---
# A sample yaml example'. 
```
